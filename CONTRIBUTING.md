# Contributing to APX

Thank you for contributing to APX.

## What You Can Contribute

- Bug fixes and optimizations
- New core Actions, Resources, or transports
- Providers, adapters, and plugins
- SDK improvements and tests
- Documentation enhancements

## Workflow

1. Fork the repository and create a descriptive feature branch.
2. Implement your changes with clean, readable code.
3. Ensure all tests pass (`pytest`).
4. Submit a Pull Request describing your changes and test coverage.

## Review Guidelines

- All tests must pass cleanly.
- Code must follow protocol schemas and deterministic execution rules.
- Security-critical operations must properly declare risk and confirmation levels.
- Secrets and tokens must be handled securely with proper redaction.
